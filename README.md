# 🎂 Forever With You

A beautiful and interactive birthday website built with React to create unforgettable birthday experiences through memories, messages, animations, and surprises.

## ✨ Features

* 🎉 Interactive birthday experience
* 💌 Personalized messages and surprise sections
* 🖼️ Memory gallery
* 🎨 Modern and responsive UI
* ⚡ Smooth user experience
* 🔥 Firebase integration

## 🛠️ Built With

* React.js
* Vite
* CSS
* Firebase
* JavaScript
